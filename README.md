# Wayline VPN — development build

Wayline is a cross-platform VPN client in development. The current desktop app uses Tauri 2 + React/TypeScript + Rust.

## Core selection

Open **Settings → Connection**:

- **Xray-core** — default desktop engine. In this build it provides a local SOCKS5 proxy only. Supported conversion from imported share links: VLESS (TLS/REALITY; TCP/WS/gRPC), VMess, Trojan and Shadowsocks. Hysteria2, TUIC and AnyTLS require sing-box.
- **sing-box** — supports the current sing-box outbound conversion and local proxy mode; TUN mode is generated by sing-box.

Xray's TUN mode is deliberately unavailable in this build. A running local SOCKS listener does not automatically route all operating-system traffic. Configure an application to use the shown local proxy, or select sing-box TUN where supported and tested.

## Core binaries

Release builds bundle the official Xray-core and sing-box executables for the target platform. Wayline resolves them from the application resources automatically; no executable path needs to be entered in Settings.

For a development build, place the matching official executables in `src-tauri/binaries/` or make them available in `PATH`:

- Xray-core: https://github.com/XTLS/Xray-core/releases
- sing-box: https://github.com/SagerNet/sing-box/releases

Do not use unofficial binary mirrors. Release workflows download the official upstream archives.

## Run the development UI

```bash
npm install
npm run dev
```

This is browser preview only. Browser mode cannot launch native VPN cores or create TUN interfaces.

## Run the native desktop application

Install Node.js, Rust, and the Tauri prerequisites for your OS, then:

```bash
npm install
npm run tauri dev
```

For a release build:

```bash
npm run tauri build
```

On Linux, install the Tauri system dependencies first. On Windows, install the Visual Studio C++ build tools and WebView2 runtime as required by Tauri.

## Android project preparation

The archive includes the Wayline Android native source overlay in `src-tauri/android/`. On a machine with Node.js, Rust, Android Studio/SDK and NDK installed, run from the repository root:

```bash
npm install
bash scripts/prepare-android.sh
npx tauri android dev
# or
npx tauri android build --apk
```

`prepare-android.sh` creates the version-matched Tauri Gradle project (`src-tauri/gen/android`) and syncs the Wayline Kotlin service, manifest permissions and libbox dependency. Do not run `tauri android init` again after preparing unless you re-run the preparation script, because init regenerates the Android project.

**Important:** the archive includes a native Android VPN source overlay and a libbox adapter, but it is not a verified ready-to-build APK. The exact gomobile API compatibility, Gradle build, TUN routing and live connection must still be compiled and tested. See [ANDROID_BUILD_HANDOFF.md](ANDROID_BUILD_HANDOFF.md) and [PLATFORM_STATUS.md](PLATFORM_STATUS.md).
