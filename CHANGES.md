# Wayline 0.2.0 — изменения

## Подключение
- Добавлено настоящее управление процессом sing-box из Rust/Tauri.
- Генерация TUN-конфигурации и локального SOCKS/HTTP proxy mode.
- Автомаршрутизация TUN, защита от маршрутных петель, DNS через удалённый прокси.
- Проверка `sing-box check`, SOCKS5 TCP-проверка удалённого соединения.
- Отображение запуска, ошибок, реального времени процесса; отключение и cleanup при выходе.
- Настройка пути к `sing-box.exe`, выбор режима и просмотр реальных логов.

## Серверы
- Удалены демонстрационные узлы.
- Импорт VLESS/REALITY, VMess, Trojan, Shadowsocks, Hysteria2 и sing-box JSON.
- Импорт обычных/base64 подписок и HTTPS URL через native Rust.
- Ручное обновление HTTPS-подписок.
- Создание/удаление/переименование профилей и сохранение в localStorage.
- Блокировка смены сервера во время подключения.

## Клиент
- Оставлены темы/оформление/двухпанельный UI.
- Подключена кнопка Connect/Disconnect.
- Вместо вымышленных метрик показано «данных нет».
- Добавлены иконки для Tauri, тесты парсера, Rust unit tests, GitHub Actions workflow.

## Что не готово
- Нет встроенного sing-box, готового EXE или автоматического UAC-эскалирования.
- Нет secure credential vault, kill switch, auto-refresh, live bandwidth metrics.
- Windows TUN и desktop сборка не проверены в текущем окружении — см. README.
